12. JS Avanzado y Antigravity (IA)

Desarrollo de Web Apps modernas delegando código a la Inteligencia Artificial.

1. El nuevo rol: Director de Proyecto (Prompting)

Desarrollar aplicaciones complejas requiere escribir muchísimo código repetitivo. En el mundo real, los programadores modernos usan asistentes de Inteligencia Artificial para acelerar este proceso.

Nosotros usaremos Google Antigravity (ya sea su entorno de Chat web o el agente integrado en Visual Studio Code). Con Antigravity, no programas escribiendo línea por línea, sino que diseñas la arquitectura y le pides a la IA que construya las piezas. A esta habilidad de pedirle cosas a la IA se la llama Prompt Engineering (Ingeniería de Prompts).

Anatomía del Prompt Perfecto

Para que la IA no se invente código inútil, tu petición (prompt) debe tener 4 partes:

  1. Rol y Contexto: "Eres un desarrollador web experto en JS puro..."
  2. Objetivo Claro: "...necesito que conectes mi archivo index.html con Firebase..."
  3. Restricciones: "...no uses frameworks como React, usa solo JS Vanilla tipo módulo..."
  4. Estructura de Salida: "...devuélveme solo el código del archivo db.js".

2. Apps Responsive (Diseño Adaptativo) con IA

Hoy en día, el 80% de los usuarios navega desde el móvil. Si intentas hacer el CSS a mano, perderás horas. Pídele a la IA que use Media Queries por ti.

Ejemplo de Prompt para Diseño Responsive:

"Tengo un contenedor HTML con 3 tarjetas (divs) que están en fila usando flexbox. Necesito que modifiques mi CSS para que el diseño sea totalmente 'Responsive'. Si la pantalla es de móvil (menos de 768px), las tarjetas deben apilarse en una columna vertical usando una Media Query. Devuélveme solo la regla CSS que debo añadir."

3. Backend: Google Firebase (Login y BBDD)

Para hacer un juego o app real, necesitas guardar datos en un servidor de Google (Firebase). En lugar de memorizar las funciones de la librería de Firebase, vamos a pedirle a la IA que nos escriba el código de conexión.

A. Autenticación (Login con Google)

La IA puede generarte el botón y el código de inicio de sesión en segundos. Usa un prompt como este:

"Actúa como ingeniero Backend. Necesito integrar 'Firebase Authentication' en mi web para que los usuarios puedan iniciar sesión con su cuenta de Google. Escríbeme el código JS necesario usando 'signInWithPopup'. Devuélveme el código comentado paso a paso para que yo pueda entenderlo e insertarlo en mi archivo auth.js. Usa la última versión de Firebase v9."

B. Base de Datos (Cloud Firestore)

Firestore es la base de datos de Firebase donde guardaremos el ranking de los jugadores o los datos de la app. Para que la IA te escriba las funciones de Guardar y Leer, debes ser muy específico con los nombres de tus 'Colecciones' (carpetas de la bbdd).

Prompt para guardar y leer puntuaciones:

"Tengo un juego en Javascript. Necesito guardar las puntuaciones en Cloud Firestore.
1. Escribe una función 'guardarPuntuacion(usuario, puntos)' que use 'setDoc' para guardar la info en la colección llamada 'ranking'.
2. Escribe una función 'mostrarRanking()' que use 'getDocs' para descargar las puntuaciones y las imprima por consola.
Asegúrate de importar las funciones correctas de 'firebase/firestore' al principio del archivo."
