17. Accesibilidad Web: Diseñar para Todos

El 15% de la población mundial tiene algún tipo de discapacidad. ¿Tu web llega a todos ellos?

1. ¿Qué es la Accesibilidad Web y por qué importa?

Asegurarse de que las personas con discapacidad puedan percibir, comprender, navegar e interactuar con la web.

  • Visual: Ceguera (usan lectores de pantalla), baja visión, daltonismo.
  • Motora: Dificultad para usar ratón; dependen del teclado (Tab, Enter).
  • Auditiva: Necesitan subtítulos para vídeos/audio.
  • Cognitiva: Necesitan interfaces predecibles y lenguaje claro.

* En España y la UE, las webs públicas están obligadas por ley a cumplir los estándares WCAG 2.1 nivel AA.

2. Los 4 Principios POUR (WCAG)

  • Perceptible: La información debe captarse por distintos sentidos (ej. alt text para imágenes).
  • Operable: La interfaz debe usarse con cualquier dispositivo (ej. navegable por teclado).
  • Comprensible: Contenido claro y formularios que avisen de errores.
  • Robusto: Código HTML estándar que funcione en lectores de pantalla.

3. Los Puntos Clave a Revisar en tu Web

1. Texto Alternativo (alt) en Imágenes

❌ <img src="logo.png">
El lector dice: "Imagen logo punto png"
✅ <img src="logo.png" alt="Logotipo del Podcast Escolar">

2. Contraste de Color

El texto debe tener suficiente contraste respecto al fondo (ratio mínimo 4.5:1). Texto gris claro sobre fondo blanco es ilegible para baja visión.

3. Etiquetas de Formularios

❌ <input type="text" placeholder="Nombre">
✅ <label for="nombre">Tu Nombre:</label> <input type="text" id="nombre">

4. Texto descriptivo en Enlaces

❌ <a href="audio.mp3">Haz clic aquí</a>
✅ <a href="audio.mp3">Escuchar el episodio 1</a>

4. Herramientas de Evaluación

  • WAVE (wave.webaim.org): Herramienta web que pinta sobre tu página iconos indicando los errores de accesibilidad.
  • Lighthouse: Incluido en las DevTools de Chrome (F12). Genera un informe con puntuación 0-100.
  • Navegación manual: Intenta navegar por tu propia web usando únicamente la tecla Tab y Enter. Si no ves dónde está el foco, tienes un problema.
