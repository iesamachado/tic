Los cimientos visuales de internet.

🌍 El Origen: Tim Berners-Lee y el CERN

En 1989, el científico británico Tim Berners-Lee, trabajando en el laboratorio europeo de física de partículas (CERN), inventó la World Wide Web (WWW). Para que los científicos de todo el mundo pudieran compartir documentos fácilmente a través de internet, inventó el HTML (HyperText Markup Language).

Su invención es uno de los mayores hitos de la humanidad: democratizó el acceso a la información y creó la base sobre la que funciona el 100% de las páginas web que visitas hoy en día. Además, decidió regalar la tecnología al mundo de forma libre, sin cobrar patentes.

HTML: La Estructura (El esqueleto)

HTML no es un lenguaje de programación, es un lenguaje de marcado. Usa etiquetas (tags) envueltas en corchetes angulares para decirle al navegador qué es cada trozo de texto. Aquí tienes las más importantes:

  • Encabezados: <h1> (Título principal), <h2>, hasta <h6>.
  • Formato de texto: <strong> (Negrita) y <em> (Cursiva).
  • Saltos de línea: <br> (Line break). A diferencia de los párrafos normales, fuerza un salto de línea sin crear un bloque nuevo. Ejemplo: Hola<br>Mundo. No tiene etiqueta de cierre.
  • Enlaces (Links): <a href="https://google.com">Ir a Google</a>. La etiqueta a (Anchor) envuelve el texto que se puede clicar, y el atributo href indica a qué web debe saltar el navegador.
  • Listas: <ul> (Lista desordenada, viñetas) y <ol> (Lista ordenada, números). Cada elemento de la lista va dentro de un <li>.
  • Imágenes: <img src="foto.jpg" alt="Descripción">. Tampoco tiene etiqueta de cierre.

Estructura de una Tabla

Las tablas requieren un montaje especial con varias etiquetas anidadas:

  • <table>: Envuelve a toda la tabla entera.
  • <tr> (Table Row): Crea una fila horizontal nueva.
  • <th> (Table Heading): Celda de título (normalmente va en negrita).
  • <td> (Table Data): Celda normal con datos.
<table border="1">
  <tr>
    <th>Nombre</th>
    <th>Nota</th>
  </tr>
  <tr>
    <td>Mario</td>
    <td>10</td>
  </tr>
</table>

CSS: El Diseño (La ropa y el maquillaje)

CSS (Cascading Style Sheets) es el lenguaje que da colores, tamaños y posiciones a las etiquetas HTML aburridas. Pero antes de pintar algo, el CSS necesita apuntar o seleccionar qué elemento HTML quiere modificar. Existen 3 formas principales de seleccionar elementos:

1. Por Elemento (Etiqueta HTML): Afecta a TODAS las etiquetas iguales.
p { color: red; } /* Todos los párrafos serán rojos */
2. Por Clase (.clase): Afecta solo a los HTML que tengan class="destacado".
.destacado { font-weight: bold; }
3. Por ID (#id): Afecta a un ÚNICO elemento exacto (ej. id="menu-principal").
#menu-principal { background: black; }

1. Tipografía y Tamaño

Podemos cambiar la fuente con font-family: Arial, sans-serif;. El ancho y alto de cualquier elemento (o de una imagen) se controla con width: 300px; y height: 200px;.

2. Teoría del Color: RGB vs CMYK

Para cambiar colores usamos color: red; (para la letra) y background-color: blue; (para el fondo). En la web, los colores se definen mediante el modelo RGB (Red, Green, Blue).

Representación visual del modelo de color tridimensional.

  • RGB (Pantallas): Es un modelo aditivo basado en luz. Si mezclas los 3 colores al máximo, obtienes luz blanca (rgb(255, 255, 255)). Si los apagas, obtienes negro.
  • CMYK (Impresoras): Es un modelo sustractivo basado en tinta (Cian, Magenta, Amarillo y Negro). Al mezclar todas las tintas oscureces el papel hasta llegar al negro. ¡Por eso los colores en pantalla siempre brillan más que impresos en papel!

3. Posicionamiento Espacial

Por defecto, los elementos HTML caen uno debajo del otro. Pero a veces queremos romper esa regla y colocar un elemento en unas coordenadas matemáticas exactas de la pantalla:

  • position: absolute;: Saca al elemento del flujo normal. Ahora puedes usar top: 50px; y left: 100px; para moverlo exactamente 50 píxeles desde el borde superior y 100 desde el izquierdo, superponiéndolo a otras cosas.
  • display: none;: Hace que el elemento desaparezca por completo, como si no existiera (muy útil en programación Javascript para ocultar ventanas).
